# Schemas

`schemas/` is not BioMesh's source of truth and doesn't replace any
existing standard. It only contains, when they exist,
`schemas/examples/`: illustrative cases showing how mappings already
documented in `standards/mappings/` connect — for example, how a real
soil-moisture case would be expressed using the correct DwC/MIAPPE/ISA
terms.

**Status: empty.** The first example gets added once `standards/mappings/`
has at least one complete mapping to illustrate — not before, to avoid
creating the appearance of a premature custom schema.

## Rule

Nothing here becomes "the BioMesh standard." If a case can't be expressed
with existing standards, that's evidence for `standards/gaps/`, not a
reason to invent a new field here.
