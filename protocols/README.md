# Protocols

Measurement protocols organized by domain. Every protocol must answer the
[scientific checklist in CONTRIBUTING.md](../CONTRIBUTING.md#checklist-for-a-new-protocol)
before being added.

A protocol references compatible hardware (`hardware/...`) and the
standard it's framed under (`standards/mappings/...`) — it doesn't
duplicate that information.
